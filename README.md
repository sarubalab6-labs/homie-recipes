# Homie Recipes 🍴

Homie Recipes is a simple and user-friendly recipe website built using HTML and CSS.

## Features

- 🏠 Home page with recipe collection
- 🍔 Burger recipe
- 🍕 Pizza recipe
- 🍝 Pasta recipe
- 🥗 Salad recipe
- 🍰 Dessert recipe
- 🥗 Appetizer recipe
- 📖 Separate recipe pages
- 🔙 Easy navigation back to the home page

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `index.html` – Home page
- `about.html` – About page
- `burger.html` – Burger recipe
- `pizza.html` – Pizza recipe
- `pasta.html` – Pasta recipe
- `salad.html` – Salad recipe
- `dessert.html` – Dessert recipe
- `style.css` – Website styling
